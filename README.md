# Lean Skills

A source-mapped Lean 4 skill for programming, theorem proving, mathematical formalization, logical verification, and project tooling.

## Included skill

- `lean4` — writes, explains, debugs, and reviews Lean 4 programs and proofs; covers core Lean, Mathlib, Lake, Elan, and the Lean 4 VS Code extension.

## Install

```bash
npx skills add shirasakaren/lean-skills
```

To select it explicitly from this repository:

```bash
npx skills add shirasakaren/lean-skills --skill lean4
```

## Knowledge base

The bundled reference snapshot was extracted on 2026-08-21 from the Lean Language Reference, the official Lean learning materials, Mathematics in Lean, Logic and Proof, The Mechanics of Proof, the Hitchhiker's Guide to Logical Verification, and Lean's editor documentation.
