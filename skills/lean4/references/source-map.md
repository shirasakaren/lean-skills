### Conversion conventions

- Code blocks are fenced with ```` ```lean ```` where the source identifies the language.
- Inline and display mathematics is preserved as LaTeX (`\(...\)`, `$$...$$`).
- Headings keep their original anchors in GitHub Flavored Markdown attribute form (`{#id}`),
  namespaced per part to avoid collisions (e.g. `{#mil-...}`); links inside each part are
  rewritten to point at those anchors. Links to pages outside this file remain absolute URLs.
- "Example" boxes, notes, warnings and admonitions are rendered as blockquotes.
- Everything else (tables, lists, images) is preserved; images link to the original sites.

### Caveats

- Interactive elements of the original sites (hover documentation, tactic-state toggles,
  live code) cannot be reproduced in plain markdown; their text content is inlined where present.
- Some rendered pages carry client-side search indices; those are not included.
- The Hitchhiker's Guide files include the Demo, Exercise and Homework sheets for every chapter.
- Some Mathlib-specific code in the books requires the corresponding Mathlib version to run.
